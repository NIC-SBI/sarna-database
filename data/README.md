# Data directory

This directory contains the approved CSV tables used by the public search interface.

The complete authoritative v1.0.0 release package is distributed through Zenodo at https://doi.org/10.5281/zenodo.21871232. The website does not provide separate file-download links.

Never place manuscripts, working spreadsheets, reviewer files, internal notes, unpublished metadata, or other private material in this repository. Keep those materials outside the repository and outside its Git history. The data/private/ and output/ directories are reserved and ignored as additional safeguards; their contents must never be committed. Excel workbooks remain ignored.

Only the approved public release tables may be used by the website.
