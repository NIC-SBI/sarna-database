# Data directory

This public directory contains no database records during the placeholder phase.

The finalized public release may later contain explicitly approved release files. The authoritative source for each release will be one finalized Excel workbook, accompanied by a generated UTF-8 CSV export and release metadata.

Never place manuscripts, working spreadsheets, reviewer files, internal notes, unpublished metadata, or other private material in this repository. Keep those materials outside the repository and outside its Git history. The data/private/ and output/ directories are reserved and ignored as additional safeguards; their contents must never be committed. Excel workbooks are also ignored during the placeholder phase.

Do not embed real database values in tests, screenshots, documentation, examples, or issue templates.
